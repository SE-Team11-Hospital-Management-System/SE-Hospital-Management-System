# Hospital Management System (HMS)

**Software Engineering Mini-Project | Team 11 | Section F | PES University**

## 1. Project Overview

The **Hospital Management System (HMS)** is a Software Engineering mini-project designed to support the management of patient records and hospital appointments.

The project focuses on developing a structured hospital management solution using **C/C++**, following software engineering principles such as requirements analysis, architectural design, implementation, testing, and documentation.

## 2. Problem Statement

**Hospital Management System**

Develop a patient record and appointment management system for hospitals using C/C++.

The project aims to organize patient information, streamline appointment-related operations, and provide a foundation for secure and reliable hospital administration.

## 4. Project Objectives

- Manage patient information in an organized manner.
- Support hospital appointment scheduling and management.
- Define secure authentication and access-control requirements.
- Develop a modular, maintainable system architecture.
- Ensure software quality through systematic testing and requirement traceability.

## 8. Development Methodology

The project follows a structured software engineering workflow:

1. Requirements gathering and analysis
2. Software architecture and detailed design
3. Implementation of assigned functional features
4. Unit and integration testing
5. System testing and defect resolution
6. Documentation and final verification

Git and GitHub are used to maintain version history, coordinate contributions, and track development progress.
